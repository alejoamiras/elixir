- 2026-09-10 · **The unreachable assertions were deleted, not rebuilt.** `loadSiteConfig` drops the environment before a production config exists, so `queryOverrides`/`prestoE2ePort` can never be truthy where `assertProductionConfig` reads them. Rebuilding the check over an "independently constructed config" would have asserted a property of a config nobody builds. The artifact inspector holds the same property over the resolved config that was actually assembled, which is the one that matters.
- 2026-09-10 · **`siteModeFrom` throws on anything but the three literals**, empty and unset falling back to the command's default (`dev` for `serve`, `production` for `build`). The test case that matters is `Production` — the capitalised misspelling used to become a relaxed build silently.
- 2026-09-10 · **The inspector reads the destination, not the config.** `artifact.ts` walks `out`, requires `build.json` (JSON, `mode: production`), requires the root `_headers` as a regular file and every `_headers` to equal `renderHeaders({mode:'production'})`, and parses every `https?://` literal in `.js`/`.mjs` through `URL` to catch a plaintext loopback host. Regex-only matching missed `HTTP://LOCALHOST`, `http://[::1]`, `http://127.0.0.2`, `http://127.1` and `localhost.` — codex found each of those; `URL` normalises all but the trailing dot, which is stripped by hand.
- 2026-09-10 · **Proving the wiring, not just the function.** A unit test of `assertProductionArtifact` says nothing about whether `assemble()` calls it on its own output after the files exist. `assemble()` now takes its four slow steps (`buildApp`, `fetchCrs`, `copyArtifacts`, `copySlots`) as a replaceable `AssemblySteps` defaulting to the real ones; the test drives a real assembly into a scratch dir with stubs that write one script, and a loopback literal in that script must reject. Chose injection over `mock.module('node:child_process')`: bun's module mocks are process-wide and `vite-base.ts` runs `execFileSync('git', …)` through the same import — the mock would have broken `sourceCommit` for every later test in the run. `GITHUB_SHA` in the test env sidesteps the git call.
- 2026-09-10 · **HTTPS-only asserted on the consumed endpoint.** `prestoEndpointFor({e2ePort:'', overrides:false})` must yield `httpsOnly: true` and https-only `acceleratorUrls`; flipping the flag must admit `http://`. The mutation half is what makes the first half load-bearing.
- 2026-09-10 · Codex fix loop (GPT-6 Astra, high, session `01a08c48…`): **round 1 changes** — missing root `_headers` passed (nested copy counted); loopback matcher case/IPv6/`127.1` gaps; no regression test that `assemble()` inspects its destination; comment cleanup (narration above fixtures and the inspector call, an intro block, two Presto-test comments). - 2026-09-10 · Bun 1.4.0 `bun test` runs every file in one process: any `mock.module` of a Node builtin leaks into later files. Prefer dependency injection for anything that shells out.
