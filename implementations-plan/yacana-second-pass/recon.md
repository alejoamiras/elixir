## Conventions to match

- Tailwind v4 arbitrary values, no new tokens (`theme.css` is the palette; `label-mono`, `eyebrow` utilities).
- `Tile` `px-[18px] py-4 rounded-[8px]`, `TileHeader` mono uppercase with a normal-case aside, `Kpi` md 22 px / lg 40 px,
  `Button` 38 / 30 / 48 px, `StatusPill` with the 5 px light, `Badge warn` for the env pill.
- Apps import the design system by relative path (`../../ui/src/index.ts`); the site config reaches them through
  Vite `define` (`VITE_*`), never `process.env`.
- Tests: Vitest for components (`*.vitest.tsx`), `bun test` for pure TS, Playwright on the isolated network through
  `bun run e2e:agent`; the stats visual gate replays a recorded fixture and compares pixels exactly.
- Comments say what the code cannot; no plan or phase references in code.

## Collision / dedup risks

- Two short-form helpers (`shortHash`, `shortAddress`) already coexist; the explorer work must not add a third.
- `LoopTile` and the new `ClaimSlot` must not both render the claim; the stepper moves, it is not copied.
- `WalletCard` and the wallet route both show the address; both get the same linked chip component.
- The stats' `sentence()` lives in `miner-core/src/metrics.ts:135` ("sat open past T_MAX … roll") and is shared
  code: the wording change happens there once.
- `LogCard.tsx` is unmounted today; the diagnostics move deletes it rather than reviving it.
